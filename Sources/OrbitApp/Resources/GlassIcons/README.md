# Glass icons (not included)

The Orbit interface was designed with a third-party "Glass" icon pack by Vinz. Its licence does not allow
sharing the icons themselves as a pack, so the PNG files are **not** in this repository.

Without them, Orbit draws SF Symbols instead (see `GlassIcons.symbols` in `Theme.swift`). Everything works the same.

If you have a licensed copy, put the files here as `glass-<index>.png` (index = file number, see `GI` in `Theme.swift`).
They are ignored by git.
