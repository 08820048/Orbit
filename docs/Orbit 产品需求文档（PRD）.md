## 1. 产品概述

Orbit 是一款本地优先的 macOS 桌面应用，能够基于真实的系统使用数据，生成可高度自定义的精美分享图。用户可以查看自己在不同时间维度下的应用使用情况（年度最常用、月度高频、单应用时长等），并一键生成适合分享到社交媒体或朋友圈的视觉化报告。

**核心卖点**：

- 真实本地数据，不上传云端
- 精美可自定义的分享图
- 极致简单的操作体验

## 5. 详细功能需求

### 5.1 数据采集


| 需求                | 优先级 | 说明                              |
| ----------------- | --- | ------------------------------- |
| 读取 Screen Time 数据 | P0  | 获取应用使用时长、启动次数等核心数据              |
| 本地补充监控            | P1  | 通过 NSWorkspace 监听前台应用切换，作为补充数据源 |
| 数据聚合              | P0  | 支持按日、周、月、年进行聚合计算                |
| 应用分类              | P1  | 自动或手动将应用分为生产力、娱乐、社交、开发等类别       |
| 数据本地存储            | P0  | 所有数据仅存储在本地                      |


**权限要求**：

- Full Disk Access（完全磁盘访问权限）
- 需要清晰的权限引导流程

### 5.2 数据维度展示

支持以下核心维度（MVP 优先实现前 3 项）：


| 维度          | 说明              | 优先级 |
| ----------- | --------------- | --- |
| 年度最常用应用     | Top 10 / Top 20 | P0  |
| 月度高频应用      | 当月使用时长排行        | P0  |
| 单应用使用时长     | 指定应用的总时长与趋势     | P0  |
| 分类使用占比      | 生产力 / 娱乐等分类占比   | P1  |
| 工作日 vs 周末对比 | 使用习惯对比          | P2  |
| 年度总使用时长     | 全年屏幕时间汇总        | P1  |


### 5.3 分享图生成器（核心功能）

**基础能力**：

- 一键生成高清分享图（PNG）
- 支持复制到剪贴板
- 支持保存到本地

**可自定义项**：


| 自定义项    | 选项               | 优先级 |
| ------- | ---------------- | --- |
| 背景      | 纯色、渐变、图片、毛玻璃效果   | P0  |
| 圆角      | 可调节圆角大小          | P0  |
| 主题色     | 主色调、强调色          | P0  |
| 字体      | 系统字体 / 自定义字体     | P1  |
| 显示内容    | 是否显示具体时长、排名、应用图标 | P0  |
| 水印 / 签名 | 可选 Orbit 水印或个人签名 | P1  |
| 布局模板    | 多种预设模板           | P0  |


**预设模板（MVP 至少 3 个）**：

1. **极简排行榜**：干净的 Top 应用列表
2. **卡片式**：突出单个或少数应用
3. **年度报告**：更完整的年度总结风格

### 5.4 其他功能


| 功能    | 优先级 | 说明                          |
| ----- | --- | --------------------------- |
| 权限引导页 | P0  | 首次启动引导用户授予 Full Disk Access |
| 数据刷新  | P0  | 手动刷新数据                      |
| 应用管理  | P1  | 隐藏不想统计的应用、重命名显示名称           |
| 导出数据  | P2  | 导出原始数据（CSV）                 |
| 深色模式  | P0  | 完整支持系统深色模式                  |

## 7. MVP 范围定义

**MVP 必须包含**：

- 读取 Screen Time 数据（年度 + 月度）
- 展示年度最常用应用 Top 10
- 生成分享图（支持背景颜色、圆角、基本主题色）
- 至少 2 个分享图模板
- 完整的权限引导流程
- 本地数据存储

**MVP 暂不包含**：

- 复杂的自定义字体
- 图片背景上传
- 应用分类统计
- 趋势图表
- 多语言（优先中文）

## 8. 技术要点与风险


| 风险点                 | 说明                         | 应对策略               |
| ------------------- | -------------------------- | ------------------ |
| Screen Time 数据读取    | 依赖私有数据库路径，系统更新可能变化         | 做好版本兼容与降级方案（纯本地监控） |
| Full Disk Access 权限 | 用户授权门槛较高                   | 设计清晰的引导流程 + 权限检测   |
| 数据准确性               | Screen Time 统计规则与用户预期可能有差异 | 在界面标注数据来源与说明       |
| 性能                  | 长时间监控可能影响性能                | 监控服务做极致优化          |
