## 1. 产品概述

**Orbit 是一款本地优先的 macOS 应用，帮你把自己 Mac 上的一切变成值得分享的内容。**

用户可以分享关于自己 Mac 的任何内容：用了什么软件、用了多久、桌面长什么样、用的是什么机器、软件怎么摆放。Orbit 负责把这些内容整理成排版精美、可高度自定义的图片，一键存图、复制，或通过系统分享菜单发出去。

**核心卖点**：

- **分享你的 Mac 的一切**：不止使用数据，还有桌面、装备、软件栈、壁纸
- **真实本地数据，不上传云端**
- **精美可自定义的卡片**：同一套编辑器，所有内容通用
- **极简的操作体验**

| 目标 | 说明 |

| 商业目标 | 打造一款有传播属性的独立 Mac 工具 |

## 3. 目标用户

- 喜欢分享生活、有仪式感的 Mac 用户
- 喜欢晒桌面、晒装备、晒「我的软件」的人
- 对个人数据有好奇心的人（年度总结爱好者）
- 设计师、开发者、内容创作者等注重视觉的用户
- 年龄大致在 18–40 岁，熟悉 macOS 操作

## 4. 核心模型：素材 → 卡片 → 导出

所有分享内容都经过同一条流水线：

```
素材 (Source)  →  卡片 (Card)  →  导出 (Export)
 取数据             排版与样式         存图 / 复制 / 系统分享
```

- **素材**：一种「关于你的 Mac 的内容」。每种素材自己负责取数据，并声明需要什么权限、有哪些默认版式。
- **卡片**：用统一的编辑器排版——背景、圆角、阴影、署名、水印、比例、版式。现有的分享图编辑器是它的雏形。
- **导出**：PNG 存储、复制到剪贴板、系统分享菜单。**所有处理都在本机完成，不上传。**

这个模型的意义：新增一种分享内容，只需要新增一种素材和它的默认版式，不需要重做界面。

## 6. 信息架构

### 6.1 导航

顶部居中菜单（已采用，取代侧边栏），重组为：

| 菜单项 | 作用 |
| ---- | ---- |
| 我的 Mac | 首页。展示所有素材的入口；每种素材一张入口卡片，带当前的缩略预览。使用数据的「总览」「单个应用」收进这里，作为「使用」素材的子页面 |
| 创作 | 卡片编辑器。选素材 → 选版式 → 调样式 → 导出 |
| 作品 | 已导出的卡片库，可以再次编辑（阶段 3） |
| 设置 | 数据与隐私、权限状态、导出偏好 |

### 6.2 核心流程

1. **从素材开始**：「我的 Mac」点一种素材 → 预览内容 → 「做成分享图」→ 进入创作
2. **从创作开始**：「创作」直接选素材与版式
3. **快速截图**（阶段 2）：菜单栏常驻图标 / 全局快捷键 → 选区或窗口 → 直接进入卡片编辑 → 导出

## 9. 隐私与权限

### 9.1 原则

- 所有数据只在本机处理，Orbit 不联网
- 默认不采集、不导出可识别个人设备的信息
- 分享前，用户看到的预览就是最终会被分享的内容

### 9.2 权限

| 权限 | 用于 | 缺失时的表现 |
| ---- | ---- | ---- |
| 完全磁盘访问 | 读取 Screen Time（使用数据） | 从授权那一刻起由 Orbit 自己记录 |
| 屏幕录制 | 桌面 / 窗口截图（阶段 2） | 其他素材照常可用，截图入口给出引导 |

每种权限都有清晰的引导页，缺失时不崩溃、不阻塞其他功能。

### 9.3 截图的隐私保护（阶段 2 的核心要求）

桌面截图最容易带出私人内容（通知、聊天窗口、邮件、密码管理器）。需要：

- 截图前可选择**排除指定应用的窗口**
- 截图后可在预览里**框选打码 / 遮挡**
- 导出前显示明确的提醒：当前画面包含哪些应用的窗口

## 10. 技术架构要点

### 10.1 分层

- **OrbitCore（数据层，可单测）**：素材的取数据逻辑、统计、本地存储
- **OrbitApp（界面层）**：首页、卡片编辑器、各素材的预览与版式

### 10.2 素材抽象

每种素材提供：

- 标识与名称、入口卡片的缩略预览
- 取数据的方法（异步，可能因缺权限而失败）
- 所需权限
- 默认版式与可选版式
- 在编辑器里暴露的专属选项

新增素材 = 新增一种实现，不改编辑器框架。

### 10.3 各素材的数据来源

| 素材 | 数据来源 |
| ---- | ---- |
| 使用数据 | knowledgeC（Screen Time）+ NSWorkspace 前台监控，存入 Orbit 自己的本地库 |
| 我的装备 | 系统接口（sysctl、ProcessInfo、显示器信息），不读取序列号 |
| 软件栈 / Dock | 已安装应用扫描（已有）、Dock 偏好设置、终端工具探测（已有） |
| 桌面壁纸 | NSWorkspace 的壁纸地址 |
| 桌面 / 窗口截图 | ScreenCaptureKit（单帧截图 API 自 macOS 14 起提供；macOS 13 需另行评估降级方案，例如系统 `screencapture`） |

### 10.4 存储

- 使用数据：本地 SQLite（已有）
- 卡片配置：本地偏好（已有）；作品库（阶段 3）需要保存导出的图片与可再编辑的卡片配置

## 12. 风险

| 风险点 | 说明 | 应对策略 |
| ---- | ---- | ---- |
| 范围膨胀 | 「分享 Mac 的一切」没有边界 | 以「素材」为单位准入；每种素材必须有明确的数据来源、权限与默认版式 |
| 截图泄露隐私 | 桌面可能包含私人内容 | 排除窗口、打码、导出前提醒（见 9.3） |
| 屏幕录制权限门槛 | 授权门槛高，易流失 | 其他素材不依赖它；独立的引导页 |
| Screen Time 数据读取 | 依赖私有数据库路径，系统更新可能变化 | 版本兼容与降级（纯本地监控） |
| 数据准确性 | Screen Time 统计规则与用户预期可能有差异 | 界面标注数据来源与说明 |
| macOS 13 兼容 | 截图 API 版本差异 | 阶段 2 前评估是否提高最低系统版本 |

## 13. 决定与待确认问题

### 已确认（2026-11-25）

1. **截图支持导入：** 除了在 Orbit 里直接截屏，也支持导入已有的图片 / 截图做美化。导入不需要屏幕录制权限，放在阶段 1；直接截屏放在阶段 2。
2. **系统分享菜单放在阶段 1。**
3. **导出只有图片**，不上传、不生成在线链接。
4. **阶段 1 包含全部四类首批素材：** 我的装备、软件栈 / Dock、桌面壁纸、导入图片美化（再加已有的使用数据）。

### 待确认

1. 阶段 2 是否需要菜单栏常驻与全局快捷键？
2. 「我的装备」想展示到什么程度（只有硬件，还是包括外设、显示器、存储占用）？
3. 作品库是否需要保存可再编辑的卡片配置，还是只留导出的图片？
4. 是否仍然把最低系统版本保持在 macOS 13？
