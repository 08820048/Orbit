## 1. 产品概述

**Orbit 是一款本地优先的 macOS 截图工具。** 菜单栏常驻，全局快捷键一按即截，截完可以标注、美化，一键复制、保存或分享。

同时，Orbit 保留了「软件分享」：把你在 Mac 上用的软件做成好看的分享图（使用时长排行、我的软件栈）。它是第二个页签，不是主入口。

**核心卖点**：

- 完整的截图工作流：捕获、标注、美化、导出
- 真实本地处理，不上传云端
- 美化和分享做得比同类更好看（沿用已有的背景、版式和导出能力）

## 2. 产品目标

| 目标 | 说明 |
| ---- | ---- |
| 核心目标 | 成为一款日常可用的 Mac 截图工具，而不只是「分享图生成器」 |
| 用户价值 | 截图更快、更好看、发出去更省事 |
| 产品差异化 | 截图和美化分享一体；本地优先；开源 |
| 商业目标 | 打造一款有传播属性的独立 Mac 工具 |

## 3. 目标用户

- 经常截图并发给别人的 Mac 用户：开发者、设计师、产品经理、内容创作者
- 写文档、发社交媒体、提 Issue 时需要把截图弄好看的人
- 喜欢晒「我的软件」的人（原有用户）

## 4. 功能需求

### 4.1 捕获

| 方式 | 说明 | 优先级 |
| ---- | ---- | ---- |
| 区域截图 | 拖选任意矩形；显示尺寸；可微调；Esc 取消 | P0 |
| 窗口截图 | 悬停高亮、点击选中；可选带阴影、圆角，透明背景 | P0 |
| 全屏截图 | 整个显示器；多显示器时选择或全部 | P0 |
| 延时截图 | 3 / 5 / 10 秒倒计时后捕获，用于截菜单、悬停状态 | P0 |
| 重复上一次区域 | 用同一个区域再截一次 | P1 |

**不做（第一版）**：滚动长截图、屏幕录制、GIF、OCR、贴图（钉在屏幕上）。

### 4.2 形态与入口

- **菜单栏常驻**：菜单栏图标，点开是菜单（各种截图方式、最近截图、打开主窗口、设置、退出）。
- **全局快捷键**：每种捕获方式一个快捷键，可在设置里自定义，冲突时提示。
- **主窗口**：页签「截图」「分享」「设置」。截图是默认页，显示历史和快速操作。
- **开机启动**：可选，默认关闭。
- **Dock 图标**：可选隐藏，只留菜单栏。

### 4.3 捕获后：快速浮窗

截图完成后，屏幕角落弹出缩略图浮窗，几秒后自动消失（可设置）：

- 复制、保存、编辑、分享、删除
- 拖拽缩略图可直接拖进其他应用
- 点击进入编辑器
- 可设置「截完直接复制」「截完直接保存」，不弹浮窗

### 4.4 标注（编辑器）

| 工具 | 说明 | 优先级 |
| ---- | ---- | ---- |
| 箭头、矩形、椭圆、直线 | 颜色、粗细可调 | P0 |
| 文字 | 字体、字号、颜色、背景 | P0 |
| 马赛克 / 模糊 | **遮挡敏感信息**，不可逆，导出时真正抹掉像素 | P0 |
| 序号标记 | 自动递增的 ①②③ | P1 |
| 荧光笔 | 高亮 | P1 |
| 裁剪 | 调整画布 | P0 |
| 撤销 / 重做 | 无限步 | P0 |

### 4.5 美化

把截图放进一张好看的画布里。**沿用已有的能力**：背景（纯色、渐变、内置图片、自选图片、毛玻璃）、圆角、阴影、边距、尺寸预设（含小红书、X、手机壁纸）、署名、水印。新增：

- 窗口边框样式（macOS 窗口外框、浏览器外框）
- 一键预设（「社交媒体」「文档」「纯净」）
- 截图作为内容放进已有的卡片版式

### 4.6 历史

- 本地保存最近的截图，默认保留 30 天或 200 张，可设置，可一键清空。
- 历史里的每一项可以重新编辑、复制、分享。
- **隐私**：历史只存在本机，设置里可以关闭。

### 4.7 导出与分享

| 方式 | 说明 |
| ---- | ---- |
| 复制到剪贴板 | ⌘C |
| 保存为文件 | PNG、JPG；默认保存目录可设置；文件名规则可设置 |
| 系统分享菜单 | 信息、邮件、隔空投送等 |
| 拖拽 | 从浮窗或编辑器拖进其他应用 |

**不上传，不生成在线链接。**

### 4.8 软件分享（原有功能，保留）

页签「分享」。内容不变：数据排行（排行榜、卡片、年度报告、气泡图）和自选软件（分组、短评、终端工具），沿用同一套背景、尺寸、导出。

### 4.9 设置

- 快捷键、保存目录、文件名规则、截完后的行为、浮窗时长
- 菜单栏与 Dock 显示、开机启动
- 权限状态与引导（屏幕录制、完全磁盘访问）
- 数据与隐私（使用数据、历史、清除）
- 更新（Sparkle，默认每天检查，可关闭）

## 5. 导航

主窗口顶部居中菜单：

| 菜单项 | 作用 |
| ---- | ---- |
| 截图 | 默认页：历史、快速操作 |
| 分享 | 原有的软件分享编辑器 |
| 设置 | 快捷键、权限、隐私、更新 |

截图编辑器是独立窗口，从浮窗或历史进入。

首次启动：权限引导（屏幕录制），完全磁盘访问只在用户进入「分享」的数据排行时才引导。

---

## 6. 范围边界：不做什么

| 不做 | 原因 |
| ---- | ---- |
| 滚动长截图、屏幕录制、GIF | 技术复杂度和维护成本高，第一版不做，后续看反馈 |
| OCR、翻译 | 与「为分享而生」关系弱 |
| 贴图（钉在屏幕上） | 同上 |
| 在线链接、云端上传 | 保持「完全本地」的隐私定位 |
| 统计仪表盘 | 使用数据只作为分享图的原料 |

---

## 7. 非功能需求

| 类型 | 要求 |
| ---- | ---- |
| 性能 | 快捷键到出现选区 < 200ms；捕获到浮窗 < 500ms；常驻时 CPU 和内存占用极低 |
| 隐私 | 所有数据本地处理，不上传任何使用数据。唯一的网络请求是检查更新，可关闭 |
| 兼容性 | macOS 14.0 及以上，Apple 芯片和 Intel |
| 稳定性 | 权限缺失、多显示器、不同缩放比例下都有友好提示，不崩溃 |
| 画质 | Retina 下按原始像素捕获，不糊；颜色空间正确（sRGB / 显示器配置） |
| 视觉 | 完整支持系统深色和浅色模式；界面扁平、一体化 |

## 8. 权限

| 权限 | 用途 | 何时需要 |
| ---- | ---- | ---- |
| 屏幕录制 | 截图（ScreenCaptureKit） | 首次使用任何截图功能 |
| 辅助功能 | 部分全局快捷键、窗口悬停识别（待验证是否必需） | 视实现而定 |
| 完全磁盘访问 | 读取屏幕使用时间，用于数据排行 | 仅在使用数据排行时，可不授权 |

## 9. 技术要点与风险

| 风险点 | 说明 | 应对策略 |
| ---- | ---- | ---- |
| **定位反复** | 这是第二次转向截图，此前四次方向变化都让已完成的部分贬值 | v5.0 起锁定；每个阶段先发布给真实用户，再决定下一阶段 |
| **竞争** | CleanShot X、Shottr、Xnapper 等已很成熟 | 不拼功能数量；把「美化和分享」做到更好；开源、免费或更低价 |
| **屏幕录制权限提示** | macOS 15 起，使用屏幕捕获的应用会周期性弹出权限确认 | 用官方推荐的 API；在设置里解释；尽量减少触发 |
| **全局快捷键** | 与系统和其他应用冲突；沙盒外才可靠 | 冲突检测；默认值避开系统快捷键 |
| **多显示器与缩放** | 不同 DPI 混合时坐标容易出错 | 专门的测试矩阵；用真实设备验证 |
| 分发渠道 | 完全磁盘访问和辅助功能不符合 Mac App Store 沙盒 | 继续直接分发（GitHub Release + Sparkle） |
| 菜单栏应用的生命周期 | 常驻、开机启动、无窗口时的行为 | 单独设计并测试 |
