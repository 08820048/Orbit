## 1. 产品概述

**Orbit 是一款本地优先的 macOS 应用，专注一件事：把你在 Mac 上用的软件，做成好看、可以直接分享的图。**

用户用两种方式生成分享图：

- **数据排行**：基于真实的使用时长，生成排行榜、卡片、年度报告、气泡图。展示的是「我最常用哪些软件」。
- **自选软件**：自己挑选想展示的软件，分组摆放，生成「我的软件栈」。可以从已安装的软件里选，也可以一键加入 Dock 里的软件、终端工具。

生成的图可以高度自定义（背景、圆角、版式、署名等），一键复制、存为图片，或通过 macOS 系统分享菜单发出去。

**核心卖点**：

- 真实本地数据，不上传云端
- 精美、可自定义的软件分享图
- 极简的操作体验

## 3. 目标用户

- 喜欢分享生活、有仪式感的 Mac 用户
- 喜欢晒「我的软件」「我的工具栈」的人（开发者、设计师、内容创作者）
- 对个人数据有好奇心、喜欢年度总结的人
- 年龄大致在 18–40 岁，熟悉 macOS 操作

## 4. 功能需求

### 4.1 使用数据（为「数据排行」提供数据）

使用数据是分享图的原料，**不提供单独的统计页面**。

| 需求 | 优先级 | 说明 |
| ---- | ---- | ---- |
| 读取 Screen Time 数据 | P0 | 获取应用使用时长、启动次数 |
| 本地补充监控 | P1 | NSWorkspace 监听前台应用切换，作为补充 |
| 本地历史库 | P0 | Screen Time 只保留约 3 周，Orbit 把读到的记录存入自己的本地库，才能做年度统计 |
| 数据聚合 | P0 | 按周、月、年聚合 |
| 应用管理 | P1 | 隐藏不想出现的应用、重命名显示名称 |
| 权限引导 | P0 | 完全磁盘访问的引导流程；未授权时从授权那一刻起由 Orbit 自己记录 |

权限要求：完全磁盘访问（Full Disk Access）。

### 4.2 分享图编辑器（核心功能）

**页面结构**：画布居中展示分享图，下方是说明与导出按钮；右侧是浮动面板，分为「内容」「样式」两页。

**内容来源**：

| 来源 | 说明 |
| ---- | ---- |
| 数据排行 | 用真实的使用时长生成。可选时间范围（年 / 月 / 周）与数量 |
| 自选软件 | 自己挑选软件并分组 |

**数据排行的版式**：

| 版式 | 说明 |
| ---- | ---- |
| 排行榜 | 干净的 Top 应用列表 |
| 卡片式 | 突出最常用的一个，附带前几名 |
| 年度报告 | 竖版，完整的年度总结 |
| 气泡 | 应用图标按使用时长大小排布，图标间距、大小差异可调 |

**自选软件的版式**：峡湾、玻璃、纸感、极简。

**自选软件的能力**：

- 从已安装的软件里挑选，按分组展示
- 内置常用分组（开发工具、写作与学习、办公等），按类别自动推荐
- 一键加入 Dock 里的软件
- 终端工具自动检测（Claude Code、Codex CLI 等，使用官方标识）
- 自定义软件（没有图标的工具，可导入图标或用首字母）

**通用样式**：背景（纯色、渐变、内置图片、自选图片、毛玻璃，遮罩与模糊可调）、圆角、比例、署名、水印、标题字体、图标大小。**所有视觉选项默认可调，不写死。**

### 4.3 导出与分享

| 方式 | 说明 |
| ---- | ---- |
| 存储为 PNG | 2x 高清，sRGB |
| 拷贝到剪贴板 | ⌘C |
| 系统分享菜单 | 信息、邮件、隔空投送等 |

**不上传，不生成在线链接。**

### 4.4 设置

数据与隐私（来源、权限状态、本地记录、上次导入）、刷新数据、清除所有记录、关于数据准确性的说明。

## 5. 导航

顶部居中菜单，只有两项：

| 菜单项 | 作用 |
| ---- | ---- |
| 分享 | 分享图编辑器（产品的全部主体） |
| 设置 | 数据与隐私、权限状态 |

首次启动时显示权限引导页。

---

## 6. 范围边界：不做什么

为防止产品再次漂移，明确写下**不做**的事：

| 不做 | 原因 |
| ---- | ---- |
| 统计仪表盘（总览、单个应用页） | 产品是「分享」，不是「分析」。使用数据只作为分享图的原料 |
| 截图、录屏 | 竞争激烈的另一个品类，与软件分享无关 |
| 「我的装备」硬件卡片、桌面壁纸、导入任意图片 | 不属于「软件」 |
| 在线链接、云端上传 | 保持「完全本地」的隐私定位 |

如果将来要扩大范围，必须先经过用户验证，而不是凭想法加。

## 7. 非功能需求

| 类型 | 要求 |
| ---- | ---- |
| 性能 | 生成分享图 < 2 秒；后台监控 CPU 占用极低 |
| 隐私 | 所有数据本地处理，无网络上传 |
| 兼容性 | 支持 macOS 13.0 及以上 |
| 稳定性 | 权限缺失时有友好提示，不崩溃 |
| 体积 | 应用体积控制在合理范围内（< 50MB） |
| 视觉 | 完整支持系统深色模式；界面扁平、一体化，不使用无意义的分割线、描边与渐变装饰 |

## 8. 技术要点与风险

| 风险点 | 说明 | 应对策略 |
| ---- | ---- | ---- |
| Screen Time 数据读取 | 依赖私有数据库路径，系统更新可能变化 | 版本兼容与降级方案（纯本地监控） |
| 完全磁盘访问权限 | 授权门槛较高，且**不符合 Mac App Store 沙盒要求** | 清晰的引导流程；发布渠道见「待确认」 |
| 数据准确性 | Screen Time 统计规则与用户预期可能有差异 | 在界面标注数据来源与说明 |
| 性能 | 长时间监控可能影响性能 | 监控服务做极致优化 |
| 定位反复 | 方向已调整多次，每次都让已完成的部分贬值 | v4.0 起锁定为「Mac 软件分享」，变更需先经过用户验证 |
